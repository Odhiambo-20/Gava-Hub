# Gava Hub

Gava Hub is organized as a frontend/backend repository.

## Projects

- `frontend/` — React, TanStack Start, and TypeScript application.
- `backend/` — Java/Spring Boot modular-monolith skeleton.
- `infrastructure/` — deployment, proxy, and monitoring configuration.
- `docs/` — architecture and API documentation.

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

The backend files are intentionally empty placeholders and are ready for the
Spring Boot implementation.
